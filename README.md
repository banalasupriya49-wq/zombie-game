# Zombie vs Home

A lightweight browser zombie defense game.

## How to run

You do not need Vite or a bundler. Just open the project in a browser:

- Double-click `index.html`, or
- run a local static server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls
- `W`, `A`, `S`, `D` = move
- Mouse = aim
- Left click = shoot

## Goal
Protect the home base and survive zombie waves.
